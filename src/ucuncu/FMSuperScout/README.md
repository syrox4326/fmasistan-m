# FMSuperScout (üçüncü taraf)

Kaynak: https://github.com/mavarobli/FMSuperScout — MIT lisansı (bkz. `LICENSE`).
Oyunun belleğini dışarıdan, yalnızca okuyarak tarar (`ReadProcessMemory`). Oyuna hiçbir şey yazmaz.

FM Asistanım değişiklikleri (`FM Asistanım:` yorumlarıyla işaretli):
- Çıktı klasörü `FMASISTAN_BELLEK_DIZINI` ile değiştirilebilir.
- `FMASISTAN_SADECE_KULUP=1`: yalnızca menajerin kulübündeki oyuncu ve teknik ekip yazılır.
- Teknik ekipte Otorite (+0x04, ham 1-20) eklendi.
- Oyuncuda ham kondisyon ve moral değerleri yazılır.
